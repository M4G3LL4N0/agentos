# Agentos North Star

## North Star

**What it is:** AgentOS is a live Noaerth venture in Developer tools. Local control plane for agent work. It records requested, attempted, executed, and verified as different facts.

**Who it serves:** It serves developers and operators shipping with AI-heavy local workflows who need a focused product surface rather than a vague concept.

**Core problem:** The target users have a real coordination, clarity, or execution gap, but existing tools either overcomplicate the workflow, hide assumptions, or fail to preserve enough context for confident action.

**Differentiated approach:** AgentOS should make the smallest useful workflow inspectable first: clear inputs, labeled demo versus live data, explicit constraints, and a product path that can be verified from the public surface and the local repo. Local repo context also identifies it as: AgentOS.

**Enduring product direction:** Build toward a durable operating loop: capture the user's situation, structure the decision or task, produce a useful artifact or action, preserve context, and make the next step obvious. Favor compounding product memory and proof over one-off polish.

**Non-negotiable principles:**
- Keep claims evidence-backed and label prototype, demo, mock, seed, and live data honestly.
- Preserve user trust: no hidden data access, no inflated maturity claims, and no destructive automation without explicit approval.
- Ship the narrow workflow before broad platform language.
- Make outputs inspectable, exportable, and useful without requiring belief in the pitch.
- Let the venture's category shape the interface, vocabulary, and success metrics.
