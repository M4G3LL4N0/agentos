# AgentOS

AgentOS is a provider-neutral Python agent execution engine and orchestration control plane. The repository defines an `agentos` command for objectives, capabilities, verification, health checks, and related workflows. Review the command help and project documentation before connecting it to production systems.

- **Version in repository:** `0.5.0`
- **License:** MIT
- **Source:** [GitHub](https://github.com/M4G3LL4N0/agentos)
- **Project site:** [https://agentos-website-ten.vercel.app](https://agentos-website-ten.vercel.app)

## Installation

The command below is the intended PyPI installation form; it is not evidence that this distribution has been published yet.

```sh
pipx install agentos
```

For a local checkout before a PyPI release:

```sh
python -m pip install .
```

## First commands

```sh
agentos --help
agentos --version
```
